## 7. Como transformar observação em finding

Após preencher, revisar cada linha:

1. O comportamento observado contraria um requisito, contrato, critério de aceite ou expectativa documentada?
2. É reproduzível no mesmo ambiente/HEAD?
3. Há evidência suficiente (nota, minuto, captura autorizada)?
4. Qual o impacto para o participante/perfil?
5. Qual a severidade sugerida?

Se a resposta for “não” para 1 ou 2, registrar como **observação**, não como finding. Encaminhar os findings para `D105-FINDINGS.md` e para a triagem da D106.
