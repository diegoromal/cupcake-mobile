# Commit
```text
[COMMIT]
Analise somente o diff staged.
Gere uma mensagem conforme `.ai/COMMIT_STANDARD.md`.
Não descreva alterações fora do diff.
Não invente Task, Requirement, Root-Cause ou BREAKING CHANGE.
Inclua `TD` somente se o diff staged criar, alterar ou resolver explicitamente
uma dívida técnica.
Retorne somente a mensagem do commit.
```
